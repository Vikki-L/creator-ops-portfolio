# 数据入口、监控与评估

[返回完整项目](../README.md) · [查看全部模块归属](../docs/module-map.md)

本目录包含投稿数据入口及四类监控 / 分析能力。B6 是上游数据流转；其他模块为同一支 UGC 团队的日常跟进和内容策略服务。

| 模块 | 在系统中的作用 |
|---|---|
| [B6 · 投稿与数据入口](B6-creator-submission-pipeline/) | 解析投稿链接、入库、追踪；输出：A1 待审、A2 明细、B1 数据 |
| [B1 · 日常运营](B1-coach-daily-monitor/) | 投稿、视频表现、任务与异常监控；输出：Coach 当日待处理事项 |
| [B3 · 周期评估](B3-ambassador-scoring/) | 按阶段评估表现、输出建议；输出：Coach 复核与培养动作 |
| [B4 · 模板与内容指导](B4-template-dashboard/) | 按模板、Creator、平台看表现；输出：模板维护与指导依据 |
| [B2 · 外部内容研究](B2-competitor-monitor/) | 竞品账号与内容数据观察；输出：内容策略和模板参考 |
