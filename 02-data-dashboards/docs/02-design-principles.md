# 02 · Design Principles · 三件套共同的设计原则

> 虽然 3 个 dashboard 服务不同业务场景，但**共用一套设计哲学**。

## 🎯 Principle 1 · 每天打开就能看

### Why
传统 BI 报表是"周报"、"月报"形式——做出来就放在那，没人主动看。
而数据看板的核心价值是**实时性 + 主动性**：让用户每天主动来看。

### How
- 数据**T+1**（最坏 T+1，理想 T+0）更新，不是月度刷新
- 首页直接展示**核心数字**（不是要点 3 层才能看到关键信息）
- 异常**自动标红**（不需要用户自己找）

### Result
> 上线后管理层和 Coach 每天上班第一件事就是打开 Daily Monitor。

---

## 🎯 Principle 2 · 按角色定制视图

### Why
- Coach 想看**自己下属**的表现（关注个人）
- Manager 想看**全员对比 + 团队整体**（关注 Coach 团队）
- 内部人员想看**全员 + 跨 Coach 横向对比**（关注资源分配）

一个 dashboard 给所有人看一样的内容 = 每个人都没法用。

### How
- **多视图切换**：同一个 dashboard 支持 "我的视图" / "团队视图" / "全员视图"
- **按 Coach 维度过滤**：每位 Coach 默认只看自己下属，可手动切换看其他 Coach
- **表头自定义**：每位用户独立保存自己关心的字段

### Example
B2 Competitor Monitor 的 31 字段五维度表 → 不同人保存不同视图：
- 内容运营关注"爆款分析"5 字段
- 增长团队关注"时间轨迹"6 字段
- 管理层关注"数据快照"6 字段

## 🎯 Principle 3 · 数据驱动 → 推荐动作

### Why
看数据本身不产生价值。**看完知道下一步做什么**才产生价值。

但很多 dashboard 只展示数字 → 用户看完还要自己想"所以呢？" → 用着用着就放弃。

### How
- 异常**直接标记建议**：不是"播放量 1200" → 是"播放量 1200 ⚠️ 低于阈值 · 建议安排 1-on-1"
- 每个看板**对接下游动作**：B3 评分 → 进入 A5 达人池清退候选；B2 竞品发现新爆款 → 进入 B4 模板候选
- **可点击下钻**：看到异常一键跳转到 Creator 详情页 / 模板详情页

---

## 🎯 Principle 4 · 跨期对比

### Why
单日数据不能说明问题。"今天 5K 视频 3 条"——是好还是坏？
对比上周同期才能判断。

### How
- 每个核心指标都**默认显示同比/环比**（不只是"3 条"，是"3 条 ↑ 比上周多 50%"）
- 支持**时间范围切换**（昨天 / 7 天 / 30 天 / 自定义）
- **跨期数据快照**（V2 加入）：能调取历史任意时间点的截面数据

### Example
Coach Daily Monitor V2 加入跨期快照后，Coach 能直接看"我下属 @abc 上周 vs 这周"的对比，不需要去翻历史 Excel。

## 🛠️ Engineering Notes

| 维度 | 设计选择 |
|------|---------|
| 前端 | HTML 可交互式原型（Cursor 生成）|
| 数据更新 | 上游数据由投稿入库 pipeline + 竞品监控 pipeline 推送 |
| 权限控制 | 按 Coach 维度过滤数据可见性 |
| 表头自定义 | 每位用户独立 view config |
